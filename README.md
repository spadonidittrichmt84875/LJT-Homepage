# LJT-Homepage

Personal academic homepage of Junteng Liu, built with the [Academic Pages template](https://github.com/academicpages/academicpages.github.io) for GitHub Pages.

## Contents

- `_pages/about.md` — the front page: personal details, academic background, research experience, publications, honors and awards, skills, and contact information.
- `_pages/publications.html` and `_publications/` — the publications page, with one Markdown file per publication.
- `_config.yml` — site-wide settings and the author sidebar.
- `_data/navigation.yml` — header navigation.
- `_data/authors.yml` — author metadata.
